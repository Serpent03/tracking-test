### How to use

- Install `uv` (which is an ultra-fast python package manager like `pip`, but better): https://docs.astral.sh/uv/getting-started/installation/
- Type `uv run smain.py`; which runs the video tracking algorithm in CSRT mode.
- Draw a bounding box over the area which you would like to track; then press `ENTER` or `SPACEBAR`.
- Press `ESCAPE` to exit; and press `C` while the video is running to re-select the tracking target.
- Check the contents of `smain.py` to see what is happening where; or to use another video with it.
